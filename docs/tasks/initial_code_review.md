# Task: Codebase Review

## Objective
Analyze the entire codebase and provide high-quality research-level feedback.

## Scope
- Model implementation correctness
- computational rigorousness
- Scalability and computational efficiency
- Reproducibility

## Output Structure

### 1. Model Understanding
- What is implemented?
- How does it map to the theoretical model?

### 2. Critical Issues
- Logical inconsistencies
- Hidden assumptions
- Potential bugs or unintended dynamics

### 3. Design Evaluation
- Data structures
- Modularity
- Extensibility

### 4. Research Risks
- Degenerate cases
- Overfitting to simulation settings
- Lack of robustness

### 5. Suggestions
- Concrete improvements (code-level and model-level)

### 6. Output
- html file that is placed under ./docs/outputs/

## Constraints
- Do not summarize code line-by-line
- Focus on research relevance, not style
